# Clean-room development boundary

`miki151/offlinemaps` is publicly viewable but, as of the project baseline on
2026-08-08, does not contain an explicit software license. This product project
therefore does not copy source code, resources, package names, or project-specific
data from that repository.

Allowed inputs are:

- Publicly described product behavior and interoperability requirements.
- Public file formats such as GPX and OSM-derived Mapsforge map files.
- Android and Wear OS platform APIs.
- Third-party dependencies with an independently verified license.
- Test data authored for this project or carrying a compatible license.

Before accepting code copied from any external project, record its origin,
version, license, and required attribution in `THIRD_PARTY_NOTICES.md`.
